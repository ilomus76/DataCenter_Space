나의 git branch 사이들의 차이를 알고 싶은데 어떻게 해야 하나요?

내 PC에 있는 로컬 브랜치끼리 비교하려면 두 브랜치 이름을 넣어 다음 명령을 사용하면 됩니다.
git diff main..dev
# main과 dev 사이에서 파일 내용이 어떻게 다른지 보여줍니다.
변경된 파일 이름만 간단히 확인하려면:
git diff --name-status main..dev
# 두 브랜치 사이에서 추가(A), 수정(M), 삭제(D)된 파일을 표시합니다.
한 브랜치에만 있는 커밋을 비교하려면:
git log --oneline main..dev
# dev에는 있지만 main에는 없는 커밋을 보여줍니다.

git log --oneline dev..main
# main에는 있지만 dev에는 없는 커밋을 보여줍니다.
예를 들어 로컬 브랜치가 main, dev, feature라면 main..feature처럼 비교할 브랜치 이름을 바꿔 실행하세요. git branch로 브랜치 이름을 확인할 수 있습니다.
참고로 git diff main..dev는 주로 파일 내용 차이를 보여주고, git log는 커밋 차이를 보여줍니다. git diff main...dev처럼 점 세 개를 쓰면 두 브랜치가 갈라진 공통 지점 이후 dev가 바꾼 내용을 비교합니다.



https://github.com/ilomus76/DataCenter_Space.git 가 제 github 주소인데요. 우선 내 PC의 각 브랜치와 github의 각 branch가 차이가 있는지 알수 있는 방법을 좀 알려주세요

GitHub 저장소와 PC의 브랜치를 비교할 때는 먼저 원격 정보를 갱신한 다음, 같은 이름의 브랜치끼리 비교하면 됩니다. 아래 명령은 Git Bash에서 실행하세요.
1. 저장소와 작업 상태 확인
git status
# 현재 브랜치와 아직 커밋하지 않은 변경사항을 확인합니다.

git remote -v
# origin이 지정하신 GitHub 저장소를 가리키는지 확인합니다.
origin이 아래 주소가 아니라면, 원격 주소를 변경할 수 있습니다.
git remote set-url origin https://github.com/ilomus76/DataCenter_Space.git
# 기존 origin의 주소를 지정하신 GitHub 저장소 주소로 변경합니다.
2. GitHub 브랜치 정보 가져오기
git fetch origin
# GitHub의 최신 브랜치와 커밋 정보를 가져옵니다.
# PC의 작업 파일이나 로컬 브랜치 내용은 변경하지 않습니다.
이제 PC와 GitHub에 있는 브랜치를 각각 확인합니다.

git branch
# PC에 있는 로컬 브랜치 목록을 봅니다.

git branch -r
# GitHub(origin)에 있는 원격 브랜치 목록을 봅니다.

git branch -vv
# 로컬 브랜치별 연결된 원격 브랜치와 앞섬/뒤처짐 여부를 확인합니다.
3. 같은 이름의 브랜치 비교
예를 들어 main 브랜치를 비교하려면:
git rev-list --left-right --count main...origin/main
# 왼쪽 숫자는 로컬 main에만 있는 커밋 수,
# 오른쪽 숫자는 GitHub origin/main에만 있는 커밋 수입니다.
결과가 0 0이면 두 브랜치의 커밋 내용이 같습니다. 예를 들어 2 1이면 로컬에만 있는 커밋이 2개, GitHub에만 있는 커밋이 1개 있다는 뜻입니다. dev 브랜치도 같은 방식으로 비교합니다.
git rev-list --left-right --count dev...origin/dev
# 로컬 dev와 GitHub origin/dev의 커밋 차이를 셉니다.
차이가 어떤 커밋인지 보려면 다음 명령을 사용합니다.
git log --oneline main..origin/main
# GitHub main에만 있는 커밋을 표시합니다.

git log --oneline origin/main..main
# 로컬 main에만 있는 커밋을 표시합니다.
git fetch origin은 비교를 위한 최신 정보만 받아옵니다. 이 단계에서는 파일을 합치거나 push하지 않으므로, 우선 git status로 미커밋 변경사항을 확인한 뒤 진행하면 됩니다.
